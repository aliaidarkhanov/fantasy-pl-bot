# Фикстуры FPL API

Реальные ответы FPL API, снятые 2026-09-30 (сезон 2026/27, завершены GW1–GW5).

Чтобы файлы были небольшими, они урезаны:

- `bootstrap-static.json` — все 38 туров, но только игроки из picks ниже;
- `fixtures.json` — матчи GW3, GW5 (сыграны) и GW6 (ещё не начался);
- `live-gw*.json` — только игроки из picks ниже, без поля `explain`;
- `standings-1941-page1.json` — имена менеджеров и команд заменены на
  `Manager N` / `Team N`.

| Файл | Случай |
|---|---|
| `picks-7294-gw5.json` | обычный капитан, сыграл (у менеджера Free Hit — на капитана не влияет) |
| `picks-3009035-gw5.json` | Triple Captain (`active_chip: "3xc"`) |
| `picks-2749551-gw3.json` | капитан не вышел, повязка перешла к вице |

Двойного тура и пропущенного тура в реальных данных пока нет — эти случаи
собраны вручную прямо в тестах `packages/core`.
